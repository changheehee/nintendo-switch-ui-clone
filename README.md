# nintendo-switch

Nintendo Switch HOME 메뉴를 React와 TypeScript로 다시 만든 개인 연습 프로젝트입니다. 닌텐도와는 관련이 없습니다.

## 실행

```bash
npm install
npm run dev
```

## 조작

- 키보드 A·B·X·Y, 방향키, H(HOME), C(캡처), +/−가 컨트롤러 버튼입니다. 마우스 클릭은 화면 터치입니다.
- 전원을 켜면 Entrance 화면이 나옵니다. 아무 버튼이나 누른 뒤 같은 버튼을 세 번 눌러 잠금을 풀면 HOME에서 OIIA CAT을 실행할 수 있습니다.
